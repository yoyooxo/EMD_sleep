# emd_sleep
# 💤 EMD 互動教學實驗室 (EMD Interactive Lab)

歡迎來到 **EMD 互動教學實驗室**！這是一個基於網頁的互動式信號處理教學工具，專門用來展示與實驗 **經驗模態分解 (Empirical Mode Decomposition, EMD)** 在睡眠腦波（EEG）或生醫信號上的應用。

---

## 📄 研究與專案大綱 (Project Outline)

### 1. 研究背景與動機
* 睡眠階段（Sleep Stages）與腦波（EEG）信號的非線性、非穩態特性分析。
* 傳統傅立葉轉換（FFT）在非穩態信號處理上的局限性。

### 2. 核心技術：經驗模態分解 (EMD)
* **篩選過程（Sifting Process）**：如何將原始信號逐步提取出本徵模態函數（IMF）。
* **殘差（Residual）分析**：提取信號的長期趨勢。

### 3. 網頁互動實驗室設計
* 實作即時信號視覺化介面。
* 提供使用者動態調整參數，觀察不同 IMF 分解結果。
